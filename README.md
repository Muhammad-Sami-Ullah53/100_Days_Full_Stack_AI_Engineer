# 🚀 100 Days of Full-Stack AI Engineering

> **100 Days. One Goal. Build Real AI Systems.**

This repository documents my **100-Day journey to becoming a Full-Stack AI Engineer / AI Systems Engineer**.

My goal is not to become a pure Data Scientist or ML Researcher.

My main focus is to learn how to build **complete AI-powered applications** from frontend to backend, databases, LLMs, RAG systems, AI agents, automation, APIs, Docker and deployment.

---

## 🎯 My Goal

By the end of these 100 days, I want to be able to build and deploy complete AI applications such as:

- 🤖 AI Chatbots
- 📚 RAG Knowledge Assistants
- 🧠 AI Agents
- ⚙️ AI Automation Systems
- 🔌 AI-powered APIs
- 💬 Conversational AI applications
- 📊 AI dashboards
- 🚀 Full-Stack AI SaaS applications

My target skill is:

**Frontend → Backend → Database → APIs → LLM → RAG → Agents → Automation → Docker → Cloud → Production**

---

# 🧭 Learning Philosophy

I am following a **practical, project-based approach**.

Instead of spending months learning technologies separately, I will learn them while building real applications.

### The learning cycle:

```text

  ↓
```
